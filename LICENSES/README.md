# Third-party license records

This directory contains license/provenance records for third-party code bundled
with WowRadio-Vanilla.

## Ace2

The official WowAce Ace2 project identifies its license as:

- LGPL v2.1
- MIT for AceOO-2.0

Files:

- `Ace2-LGPL-2.1.txt` — full GNU LGPL v2.1 license text.
- `Ace2-LICENSE-NOTICE.md` — source-specific license record and references,
  including the AceOO-2.0 MIT designation.

The presence of these files does not apply the Ace2 licenses to historical
WowRadio code.

See `../THIRD_PARTY_NOTICES.md` for scope.
