# WowRadio-Vanilla project identity

## Canonical project

The canonical repository designated by the current maintainer is:

- https://github.com/Dusk-92/WowRadio-Vanilla

Mirrors, package caches, downstream forks, repackaged copies, and modified
versions hosted elsewhere are independent unless the canonical project
explicitly states otherwise.

## Independent community project

WowRadio-Vanilla is an independent community-maintained addon.

It is not affiliated with, sponsored by, approved by, or endorsed by Blizzard
Entertainment.

Compatibility with World of Warcraft 1.12-compatible clients or private/community
server environments does not imply affiliation with Blizzard Entertainment or
with any server operator.

World of Warcraft, Warcraft, Blizzard Entertainment, and associated names,
marks, artwork, and game assets remain the property of their respective rights
holders.

## Radio stations

The radio stations, networks, stream operators, names, and trademarks listed by
the addon are independent third parties.

A station appearing in `Stations.lua` does not mean that the station sponsors,
endorses, supports, or is partnered with WowRadio-Vanilla.

WowRadio-Vanilla does not host the station audio; it passes a remote stream URL
to the game client's music playback system.

## Historical upstream relationship

The current project descends from older WowRadio code, including the Vanilla
backport preserved at `Daribon/WowRadio` and later work in
`paokkerkir/WowRadio-Vanilla`.

The current maintainer does not claim authorship of inherited code merely
because it is present in the canonical repository.

See `THIRD_PARTY_NOTICES.md` and `Docs/CODE_PROVENANCE.md`.

## Support boundary

Dusk-92 is responsible only for changes and releases published by the canonical
maintained project. Historical authors, Ace2 maintainers, Blizzard
Entertainment, and listed radio stations are not responsible for this fork or
its current behavior.
