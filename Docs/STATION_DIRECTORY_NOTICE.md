# WowRadio-Vanilla station directory notice

Audit date: 2026-08-31

## What the repository contains

`Stations.lua` contains a directory of:

- remote stream URLs;
- station/display names;
- short descriptive labels;
- categories used by the addon UI.

## What the repository does not contain

WowRadio-Vanilla does **not** bundle the audio programming delivered by those
remote streams.

Playback is requested at runtime through the World of Warcraft client's music
system using the station's remote URL.

## No affiliation or endorsement

Station names, service names, trademarks, and stream brands remain the property
of their respective owners.

Inclusion in the station directory does not imply:

- sponsorship;
- endorsement;
- affiliation;
- partnership;
- ownership;
- permission to redistribute the station's audio outside the station's own
  stream.

## Independent stream operation

Each stream is operated independently of WowRadio-Vanilla. Availability,
content, geographic restrictions, formats, URLs, and terms can change without
notice to this repository.

The addon only provides a user-facing pointer to the configured stream endpoint.

## Maintenance/removal

If a station operator changes or withdraws a public stream endpoint, the
directory entry should be updated or removed.

Maintainers should avoid embedding station audio files directly into the addon
unless separate redistribution rights have been clearly established.
